ヘルプ・使い方

最終更新日：2026年10月6日

1. はじめる

エディタを開くと、最初に次のどれかを選びます。

  • 白紙で始める：32×32 の何もないキャンバスから描きます。
  • 画像を読み込む：写真などの画像をドット絵に変換して始めます。
  • 作品ファイルを開く：「作品ファイルとして保存」したファイルの続きを描きます。
  • ギャラリーから開く：クラウドに保存した作品を開きます（ログインが必要です）。
  • 前回の続きから：自動保存された前回の作品を開きます（前回描いていたときだけ出ます）。

2. 画面の上のボタン

ボタンできること
白・灰・黒の丸キャンバスの周りの背景色を変えます。描いた絵の色は変わりません。
🔲キャンバスの市松模様（透明の目印）を出す・消すを切り替えます。
🎞アニメーションのコマの一覧を出す・しまうを切り替えます（スマホでは「ファイル」の中にあります）。
↩ 元に戻す / ↪ やり直し直前の操作を取り消す・取り消したのをやり直します（50回まで）。
クリア今のレイヤーの絵を消します。
📁 ファイル新規キャンバス・作品ファイルを開く・保存・ギャラリー・ログインなどのメニューです。

画面の右上には、参考画像のボタンと、テンプレート図形のボタンがあります。右下には拡大縮小と、PEPORIS のボタンがあります。

3. 描く

ツール

ツール使い方
✏️ ペン（Q）マスを今の色で塗ります。
🪣 塗り潰し（W）つながった同じ色の範囲を、今の色で塗ります。
🧹 消しゴム（A）マスを透明にします。
💉 スポイト（S）押したマスの色を、今の色にします。マウスでは、カーソルの横に拡大鏡が出ます。指・Pencil では、触れている間は拡大鏡が付いてきて、離したマスの色を取ります。取ったらペンに戻ります。
✥ 移動（V）選択範囲の中身（選択が無ければレイヤー全体）をドラッグや矢印キーで動かします。「全レイヤー」にすると、ロックしていない全部のレイヤーをまとめて動かします。

描画スタイル（ペン・消しゴム）

  • 通常：押したマスだけを塗ります。
  • 縦 / 横：押したマスの縦一列・横一列をまとめて塗ります。
  • 線を検知（縦・横のとき）：描き始めたマスと違う色にぶつかったところで止まります。色の上から描き始めると、その色が続く範囲だけを塗り替えます。

描画サイズ

ペン・消しゴムで一度に塗る大きさです（1〜10マス）。

テンプレート図形

右上の図形のボタンから、直線・円・四角・ひし形・ハートを選び、キャンバスをドラッグして描きます。それぞれ「塗り潰し」と「枠のみ」があります。

選択

  • 📐 範囲：ドラッグで選びます。「四角で囲う」と「自分で指定」（自由な形）があります。
  • 🎨 色：押したマスと同じ色を、キャンバス全体から選びます。
  • 💧 隣接色：押したマスとつながった同じ色だけを選びます。
  • 選択している間は、選択範囲の中にだけ描けます。切り取り・コピー・貼り付けもできます。

4. 色

  • カラー：48色の基本パレットです。押すとその色で描けます。
  • 🎨 色を選ぶ：輪っか状のカラーピッカーで好きな色を選べます。外側の輪で色合い、内側の四角で鮮やかさと明るさを選びます。色のコード（#RRGGBB）を直接入れることもできます。
  • 💉（色を選ぶ画面の中）：画面に見えている色を拾ってピッカーに入れます。パソコンの Chrome・Edge では画面のどこからでも、それ以外ではキャンバス・参考画像・パレットから拾えます。
  • カスタムカラー：自分で決めた色を48個まで登録できます。「＋」で追加、「削除」を押してから色を押すと削除できます。パレットのファイル（.hex / .gpl / .pal / .txt / 画像）の書き出し・読み込みもできます。
  • 切り出し：「カラー」「カスタムカラー」の見出しの右のボタンで、パレットをパネルから切り出して、画面の好きな場所に置けます。
  • 色の履歴：画面の左下に、最近使った色が丸で並びます。押すとその色に戻せます。一番大きい丸（今の色）を押すとカラーピッカーが開きます。

5. レイヤー

左のパネルの「レイヤー」タブで操作します（タブレットでは画面の上の 🗂）。上にあるレイヤーほど手前に表示されます。

ボタンできること
＋ 追加新しいレイヤーを今のレイヤーの上に追加します。
↑ / ↓今のレイヤーを上・下へ動かします（右端の ⠿ をドラッグしても並べ替えられます）。
🗑今のレイヤーを削除します。
⧉ 複製今のレイヤーをコピーします。
⬇ 下と結合今のレイヤーを、すぐ下のレイヤーと1枚にまとめます。
🔒今のレイヤーをロックして、描けないようにします。
⬌ 左右反転 / ⬍ 上下反転今のレイヤーの絵を反転します。
👁レイヤーを表示する・隠すを切り替えます。
不透明度今のレイヤーの濃さを変えます。

レイヤーの名前は、名前をダブルクリック（ダブルタップ）すると変えられます。

6. キャンバス

  • グリッドサイズ：4×4 〜 1024×1024 まで、縦横別々に決められます。「適用」で変わります。描いた絵は残ります。
  • 表示：グリッド線・定規・中心線を出す・消すを切り替えます。
  • 列・行を強調：定規を押す（ドラッグする）と、その列・行に色が付いて目印になります。
  • 拡大縮小：右下の −・＋、Ctrl を押しながらホイール、またはピンチで変えます。
  • 移動：右ドラッグ、ホイール、または2本指で動かします。
  • 絵だけを見る：D キーを押している間（または右下の 👁 を押している間）、グリッドや市松模様を消して描いた絵だけを表示します。

7. 画像を使う

  • 画像から変換：写真などをドット絵に変換し、新しいレイヤーとして重ねます。変換方式（最頻色・平均色）や色数、「指定した色だけで変換する」を選べます。
  • トレース：画像をキャンバスの下（または上）に半透明で敷いて、なぞって描けます。保存する絵には入りません。
  • 参考画像：右上の画像のボタンで、画面に小さなウィンドウで画像を浮かべておけます。ドラッグで動かし、右下の角で大きさを変えられます。スポイトツールで画像を押すと、その色を取れます。

8. アニメーション・GIF

画面の上の 🎞（スマホでは「ファイル ▸ アニメーション（コマ）」）で、画面の下にコマの一覧を出します。コマはそれぞれのレイヤーを持ちます。

ボタンできること
▶ / ■アニメを再生・停止します。再生中にキャンバスに触れても止まります。
fps1秒に何コマ進むか（1〜50）です。再生と GIF の速さになります。
このコマ ___ ms今のコマだけ表示する時間（ミリ秒）を変えます。空にすると fps に合わせます。
👻前のコマ（赤）と次のコマ（青）を薄く重ねて表示します。
＋ 複製 / ＋ 空今のコマのコピー、または空のコマを、すぐ後ろに追加します。
◀ / ▶今のコマを前・後ろへ動かします。
🗑今のコマを削除します。
GIF保存全部のコマを GIF アニメとして保存します。

一覧の小さな絵を押すと、そのコマに切り替わります。コマの操作も元に戻せます。

9. 保存する

「📁 ファイル ▸ 💾 保存」から選びます。

保存のしかた内容
PNG保存 / 透過保存今のコマの絵を画像として保存します。倍率（×1〜×32）を選べます。ゲームの素材などには ×1（1ドット＝1ピクセル）がおすすめです。
🎞 GIF保存全部のコマを、くり返し再生する GIF アニメにします。背景（白・透明）と倍率を選べます。GIF は256色までなので、色が多いときは近い色にまとめます。
📄 作品ファイルとして保存レイヤーやコマも含めて、自分のフォルダにファイルで保存します。「作品ファイルを開く」で続きを描けます。
🧱 PEPORISに保存今の絵（選択範囲があればその中だけ）を、PEPORIS のカスタムブロックにします。
☁ クラウド保存Google アカウントでログインすると、作品をクラウドに保存できます（1人10個まで）。「ギャラリー」から開けます。

描いている内容は、このブラウザに自動保存されています。次に開いたとき「前回の続きから」で再開できます。

10. スマホ・タブレットで使う

  • ボタンを長押しすると、そのボタンの説明が出ます。
  • スマホでは、画面の左の端の ◀ ▶ で道具のパネルを出す・しまうを切り替えます。
  • タブレット（iPad など）では、左に道具、右（縦向きでは下）に色が並びます。
  • Apple Pencil で初めて描くと、「Pencil で描き、指は移動・拡大縮小に使う」に切り替わります。左の道具バーの ☝ で、指でも描けるように切り替えられます。
  • 2本指でピンチすると拡大縮小、2本指で動かすとキャンバスの移動です。

11. おまけ：PEPORIS

右下のブロックのボタンで、今のキャンバスの大きさを盤面にしたテトリス風のゲームが遊べます。 メニューの BLOCKS で出てくるブロックを選んだり、自分で描いたブロック（カスタムブロック、10個まで）を使ったりできます。 「盤面をレイヤーに残して終了」で、遊んだ盤面を絵として残せます。

13. 困ったとき

描いた絵が消えてしまった

同じブラウザでエディタを開き直し、「前回の続きから」を押してください。自動保存された作品が開きます。大事な作品は「作品ファイルとして保存」やクラウド保存もしておくと安心です。

描けない

  • 今のレイヤーがロック（🔒）されていないか確かめてください。
  • 選択範囲があると、その中にしか描けません。「選択解除」で外せます。
  • タブレットで指で描けないときは、左の道具バーの ☝ を押して「指でも描く」にしてください。

クラウドに保存できない

クラウド保存は1人10個までで、大きすぎる作品（コマがとても多いなど）は保存できません。ギャラリーで不要な作品を削除するか、「作品ファイルとして保存」をお使いください。

PEPORIS のカスタムブロックが消えた

カスタムブロックはそのブラウザだけに保存されます。iPhone・iPad の Safari では、サイトを7日ほど開かないと消えることがあります。ブラウザのデータを消したときも消えます。

GIF の色が少し変わった

GIF は256色までしか使えないため、それより多い色を使った絵は、近い色にまとめて保存されます。
