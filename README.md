# SuperDotEditor-KAI（スーパードットエディター・改）

ブラウザで使えるドット絵エディタです。インストール不要で、パソコンでもスマホでも描けます。

**▶ https://11kawauso.github.io/SuperDotEditor-KAI/**

## 主な機能

### 描く
- **ツール**：ペン・塗り潰し・消しゴム・スポイト・移動
- **描画スタイル**（ペン・消しゴム）：通常／縦一列／横一列（「線を検知」をオンにすると、描き始めたマスと違う色にぶつかったところで止まります。色の上から描き始めた場合は、その色が続く範囲を塗り替えます）
- **描画サイズ**：1〜100マス
- **テンプレート図形**：直線・円・四角・ひし形・ハート（塗り潰し／枠のみ）
- **選択**：範囲（四角・自由な形）、同じ色、隣接する同じ色。切り取り・コピー・貼り付けに対応
- **元に戻す／やり直し**：50回まで
- **直線**：ペン・消しゴムで Shift＋クリックすると、前に描いたマスからまっすぐ結ぶ
- **色を拾う**：Alt（Mac は option）＋クリックで、道具を持ち替えずにその色を拾う

### 色
- 24色の基本パレットと、自由に登録できる48枠のカスタムカラー（選んでいる枠をもう一度押すと、その枠の色を変えられる。見出しの右のボタンで、パネルから切り出して画面の好きな場所に置ける）
- 輪っか状のカラーピッカー（外側の輪で色相、内側の四角で鮮やかさ・明るさ）。カラーコード（#RRGGBB）の入力や、対応ブラウザでは画面から色を拾うこともできます
- パレットの書き出し（`.hex` / `.gpl`）と読み込み（`.hex` / `.gpl` / `.pal` / `.txt` / 画像）
- キャンバスの左下に直近で使った色の履歴を表示

### キャンバス
- グリッドサイズは 4×4 〜 1024×1024（縦横別々に指定可能）。小さくしてはみ出した所は覚えていて、また大きくすると元どおり出てくる
- レイヤー：追加・複製・並べ替え・下と結合・ロック・左右／上下反転・不透明度・名前の変更
- 定規と、指定した列・行の強調表示
- 中心線（マス数が偶数なら真ん中の境目に線、奇数なら真ん中の列・行を色付け）
- 市松模様（透明の目印）の四角の大きさ（1〜64マス）と、キャンバスの周りの色（白・灰・黒・好きな色）を「表示」メニューで変えられる
- 拡大縮小（ホイール＋Ctrl、ピンチ、Ctrl＋＋／−）と、右ドラッグでの移動
- 開いたときは全体が収まる大きさで表示。右下の ⛶（Ctrl＋0）でいつでも全体表示に、倍率の数字（Ctrl＋1）で100%に戻せる
- 画面のいちばん下の帯に、今の道具・描画サイズ・カーソルの位置と色・グリッドサイズ・倍率を表示
- **D キー**（または右下の👁）を押している間、描いた絵だけを表示
- **画面の並び**：左に道具バー、上の1段目にメニュー（ファイル・編集・選択・キャンバス・画像・表示・ヘルプ）、2段目の左端に元に戻す・やり直し・レイヤーをクリア、その右に今の道具の設定（選んでいる道具に合うものだけ）、右に色とレイヤーのパネル。キャンバスのスクロールバーは、場所を取らない細いものを重ねて表示します。グリッドサイズ・画像から変換・トレース・表示の切り替えなど、たまに使うものは上のメニューにまとめています
- **タブレット・スマホ**：タブレットはパソコンと同じ並び（縦向きでは色とレイヤーのパネルが下）。スマホは道具バーが下に並び、色とレイヤーのパネルは右上の 🎨 で下から出します。タブレットでは Apple Pencil で描き、指はキャンバスの移動・拡大縮小に使えます（道具バーの ☝ で指でも描けるように切り替え可能）

### アニメーション
- ヘッダーの **🎞**（スマホでは「表示 ▸ アニメーション」）で、画面の下にコマの一覧を出せます
- コマの複製・空のコマの追加・削除・並べ替え。各コマはそれぞれのレイヤーを持ちます（元に戻す・作品ファイル・クラウド保存にも対応）
- 速さ（1〜50fps）を決めて、その場で再生して確かめられます。コマごとに表示時間（ミリ秒）を変えることもできます
- 👻 で前のコマ（赤）と次のコマ（青）を薄く重ねて表示し、動きをつなげて描けます
- **🦴 ボーン（B）**：レイヤーごとに描いたパーツに骨を入れ（親子関係あり・自動割り当て可）、関節で回してポーズを付けられます。回した絵は RotSprite でドットを崩さずに描き直し、覚えたポーズの間をなめらかにつないだコマを自動で作れます（往復・ゆっくり始まる動きも可）

### AI に描いてもらう（試験中）
- AI のチャット（Claude のデスクトップアプリなど）から、MCP でエディタを直接操作してドット絵を描いてもらえます。「ファイル ▸ AI に描いてもらう」で接続します。準備のしかたはヘルプ（`help.html`）か [mcp/README.md](mcp/README.md) を見てください。エフェクト・アイテム・アイコンが得意です。描いた作品を作品ファイルとして保存してもらったり、作品ファイルを開いて続きを描いてもらったりもできます（デスクトップアプリでは、ギャラリーに保存してもらえます）

### 画像を使う
- **画像から変換**：写真などをドット絵に変換（色数の指定や、指定した色だけでの変換が可能）。1色の背景を消したり、元の画像から調べた輪郭線（外側・内側）を描き足したりもできます
- **トレース**：画像をキャンバスの下（または上）に半透明で敷いてなぞる
- **参考画像**：画面上に小さなウィンドウで画像を浮かべておく

### 保存
- **PNG保存**：倍率を選んで書き出し（背景あり／透過）
- **GIF保存**：全部のコマを、くり返し再生するGIFアニメとして書き出し（倍率・白い背景／透過を選べます。GIFは256色までなので、多いときは近い色にまとめます）
- **自動保存**：ブラウザに自動で保存され、次に開いたとき「前回の続きから」再開できます
- **作品ファイル**：レイヤーなども含めて自分のフォルダにファイル（`.dotkai.json`）として保存し、あとで開いて続きを編集できます
- **ギャラリーに保存**（Ctrl+S）：ログインなしで、作品をいくつでもこのブラウザの中（IndexedDB）に保存し、一覧から開けます。開いている作品には上書き、Ctrl+Shift+S で名前を付けて新しく保存
- **クラウド保存**：Googleアカウントでログインすると、作品をクラウドに保存してクラウドのギャラリーから開けます（1人10個まで）
- **アプリとして入れる（PWA）**：Chrome・Edge の「インストール」や、iPad の「ホーム画面に追加」で、タブやアドレスバーの無いウィンドウで開けます。オフラインでも開けます

### おまけ：PEPORIS
今のキャンバスサイズがそのまま盤面になる、テトリス風の落ち物パズルです（右下のブロックのボタンから）。
横1000マスでも遊べます。揃うかどうかは別として。

- ブロックの色はカスタムカラーから選ばれます（空ならランダム）
- 100×100 以上の盤面では、十字・ハートなどの特殊ブロックが出てきます
- 今の絵を足場にして遊んだり、遊び終わった盤面をレイヤーとして残したりできます
- ホーム画面右下のブロックから入ると、本家と同じ設定（10×20・決まった色・SRS回転・白一色の盤面）で遊べます
- 始める前に2つのモードから選べます（前回選んだモードを覚えています）
  - **NORMAL**：本家と同じルール。着地しても少しの間は動かせて（15回まで）、ゆっくり落とすと1段1点、一気に落とすと1段2点も入ります
  - **HARD**：このサイトの独自ルール。着地したら0.5秒で固定され、得点はライン消去のみです
- ゲームオーバーやポーズからメニューに戻れるので、エディタに戻らずに続けて遊べます
- メニューの **BLOCKS** で、ゲームに出てくるブロックを選べます（初めは全部。盤面以上の大きさのブロックは選べません）
- エディタで描いた絵（選択範囲があればその中だけ）を、色のまま**カスタムブロック**として保存できます（10個まで・最大1024×1024）。BLOCKS の「ブロックを作る」でエディタに移り、「ファイル ▸ 保存 ▸ PEPORISに保存」で保存します。保存先はこのブラウザ（IndexedDB）なので、ほかの端末やブラウザには引き継がれません

ビルドは不要で、HTML・CSS・JavaScript のファイルをそのまま配信しています。

## 手元で動かす

Python 3 が必要です。

```bash
python dev_server.py 8123
```

ブラウザで http://localhost:8123 を開きます。このサーバーはブラウザにキャッシュさせないので、ファイルを編集したら再読み込みするだけで反映されます。

## デスクトップアプリ（Windows）

`desktop/` フォルダに、サイトと同じエディタを専用のウィンドウで開くデスクトップアプリ（Electron）があります。

- タブやアドレスバーが無いので、キャンバスを広く使えます（F11 で全画面）
- ログイン・クラウド保存・PEPORIS は入っていません
- 「ギャラリーに保存」（Ctrl+S）すると、`ドキュメント\SuperDotEditor` に作品ファイル（`.dotkai.json`）として保存します。数の上限はありません。削除した作品はごみ箱に移ります。このフォルダのファイルは、ブラウザ版の「作品ファイルを開く」でも開けます

### 組み立て方

Node.js が必要です。

```bash
cd desktop
npm install
node node_modules/electron/install.js
```

最後の行は、`npm install` が Electron 本体のダウンロードを止めたとき（`allow-scripts` の警告が出たとき）だけ必要です。

```bash
npm start
```

で、組み立てずにそのまま起動して確かめられます。

```bash
npm run build
```

で、`desktop\dist\SuperDotEditor-KAI Setup 1.0.0.exe`（インストーラー）ができます。署名をしていないので、初めて実行すると Windows の「PC が保護されました」が出ます。「詳細情報 ▸ 実行」で入れられます。

アプリはサイトのファイルを中に持っているので、`editor.html` や `script.js` などを直したら、`npm run build` し直して入れ直すと反映されます。
