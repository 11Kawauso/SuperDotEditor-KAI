# SuperDotEditor-KAI（スーパードットエディター・改）

ブラウザで使えるドット絵エディタです。インストール不要で、パソコンでもスマホでも描けます。

**▶ https://11kawauso.github.io/SuperDotEditor-KAI/**

## 主な機能

### 描く
- **ツール**：ペン・塗り潰し・消しゴム・スポイト・移動
- **描画スタイル**（ペン・消しゴム）：通常／縦一列／横一列（「線を検知」をオンにすると、描き始めたマスと違う色にぶつかったところで止まります。色の上から描き始めた場合は、その色が続く範囲を塗り替えます）
- **描画サイズ**：1〜10マス
- **テンプレート図形**：直線・円・四角・ひし形・ハート（塗り潰し／枠のみ）
- **選択**：範囲（四角・自由な形）、同じ色、隣接する同じ色。切り取り・コピー・貼り付けに対応
- **元に戻す／やり直し**：50回まで

### 色
- 48色の基本パレットと、自由に登録できる48枠のカスタムカラー（見出しの右のボタンで、パネルから切り出して画面の好きな場所に置ける）
- 輪っか状のカラーピッカー（外側の輪で色相、内側の四角で鮮やかさ・明るさ）。カラーコード（#RRGGBB）の入力や、対応ブラウザでは画面から色を拾うこともできます
- パレットの書き出し（`.hex` / `.gpl`）と読み込み（`.hex` / `.gpl` / `.pal` / `.txt` / 画像）
- 左下に直近で使った色の履歴を表示

### キャンバス
- グリッドサイズは 4×4 〜 1024×1024（縦横別々に指定可能）
- レイヤー：追加・複製・並べ替え・下と結合・ロック・左右／上下反転・不透明度・名前の変更
- 定規と、指定した列・行の強調表示
- 中心線（マス数が偶数なら真ん中の境目に線、奇数なら真ん中の列・行を色付け）
- 拡大縮小（ホイール＋Ctrl、ピンチ）と、右ドラッグでの移動
- **D キー**（または右下の👁）を押している間、描いた絵だけを表示
- **タブレット（iPad など）用レイアウト**：左に道具バー、右（縦向きでは下）に色パネルを並べ、キャンバスを大きく表示します。Apple Pencil で描き、指はキャンバスの移動・拡大縮小に使えます（道具バーの ☝ で指でも描けるように切り替え可能）

### アニメーション
- ヘッダーの **🎞**（スマホでは「ファイル ▸ アニメーション（コマ）」）で、画面の下にコマの一覧を出せます
- コマの複製・空のコマの追加・削除・並べ替え。各コマはそれぞれのレイヤーを持ちます（元に戻す・作品ファイル・クラウド保存にも対応）
- 速さ（1〜50fps）を決めて、その場で再生して確かめられます

### 画像を使う
- **画像から変換**：写真などをドット絵に変換（色数の指定や、指定した色だけでの変換が可能）
- **トレース**：画像をキャンバスの下（または上）に半透明で敷いてなぞる
- **参考画像**：画面上に小さなウィンドウで画像を浮かべておく

### 保存
- **PNG保存**：倍率を選んで書き出し（背景あり／透過）
- **GIF保存**：全部のコマを、くり返し再生するGIFアニメとして書き出し（倍率・白い背景／透過を選べます。GIFは256色までなので、多いときは近い色にまとめます）
- **自動保存**：ブラウザに自動で保存され、次に開いたとき「前回の続きから」再開できます
- **作品ファイル**：レイヤーなども含めて自分のフォルダにファイル（`.dotkai.json`）として保存し、あとで開いて続きを編集できます
- **クラウド保存**：Googleアカウントでログインすると、作品をクラウドに保存してギャラリーから開けます（1人10個まで）

### おまけ：PEPORIS
今のキャンバスサイズがそのまま盤面になる、テトリス風の落ち物パズルです（右下のブロックのボタンから）。
横1000マスでも遊べます。揃うかどうかは別として。

- ブロックの色はカスタムカラーから選ばれます（空ならランダム）
- 100×100 以上の盤面では、十字・ハートなどの特殊ブロックが出てきます
- 今の絵を足場にして遊んだり、遊び終わった盤面をレイヤーとして残したりできます
- ホーム画面右下のブロックから入ると、本家と同じ設定（10×20・決まった色・SRS回転・白一色の盤面）で遊べます
- 始める前に2つのモードから選べます（前回選んだモードを覚えています）
  - **NORMAL**：本家と同じルール。着地しても少しの間は動かせて（15回まで）、ゆっくり落とすと1段1点、一気に落とすと1段2点も入ります
  - **HARD**：このサイトの独自ルール。着地したら0.5秒で固定され、得点はライン消去のみです
- ゲームオーバーやポーズからメニューに戻れるので、エディタに戻らずに続けて遊べます
- メニューの **BLOCKS** で、ゲームに出てくるブロックを選べます（初めは全部。盤面以上の大きさのブロックは選べません）
- エディタで描いた絵（選択範囲があればその中だけ）を、色のまま**カスタムブロック**として保存できます（10個まで・最大1024×1024）。BLOCKS の「ブロックを作る」でエディタに移り、「ファイル ▸ 保存 ▸ PEPORISに保存」で保存します。保存先はこのブラウザ（IndexedDB）なので、ほかの端末やブラウザには引き継がれません

| キー | 操作 |
| --- | --- |
| ← → | 移動 |
| ↓ | ゆっくり落とす |
| Space | 一気に落とす |
| ↑ / X | 右回転 |

| C | ホールド |

## キーボードショートカット（エディタ）

| キー | 操作 |
| --- | --- |
| Q / W / A / S / V | ペン / 塗り潰し / 消しゴム / スポイト / 移動 |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直し |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 貼り付け |
| Ctrl+A | すべて選択 |
| Delete | 選択範囲を消す |
| 矢印キー | 移動ツールで1マスずつ動かす（Shiftで10マス） |
| D（押している間） | 描いた絵だけを表示 |

Mac では Ctrl の代わりに ⌘ を使います。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ホーム画面 |
| `editor.html` | エディタ本体 |
| `script.js` | エディタの処理 |
| `anim.js` | アニメーションのコマの一覧・再生・GIF保存 |
| `tetris.js` | PEPORIS |
| `cloud.js` | ログイン・クラウド保存（Firebase Authentication / Cloud Firestore） |
| `style.css` | エディタとPEPORISの見た目 |
| `terms.html` / `privacy.html` / `legal.css` | 利用規約・プライバシーポリシー |
| `firestore.rules` | Firestore のセキュリティルール（各ユーザーは自分の作品だけ読み書き可能・1人10個まで・大きさにも上限） |
| `dev_server.py` | 開発用のサーバー |

ビルドは不要で、HTML・CSS・JavaScript のファイルをそのまま配信しています。

## 手元で動かす

Python 3 が必要です。

```bash
python dev_server.py 8123
```

ブラウザで http://localhost:8123 を開きます。このサーバーはブラウザにキャッシュさせないので、ファイルを編集したら再読み込みするだけで反映されます。
